## 二、遗留债务（按优先级）

### P1（影响体验/性能，建议下一批清）
1. **两套 SongRow 并存**：`src/components/SongRow.tsx`（通用）vs `MyLibraryScreen.tsx` 内局部 SongRow——TV 遥控焦点断链根因（批E 在册）。修法：统一到通用件，MyLibrary 局部版退役。
2. **底部让位 58 处分散写法**：MiniPlayer 高度让位有 paddingBottom:140/40/自定义等多种——滚动到底被遮/空隙过大两极问题。修法：抽 `useBottomInset()` hook 统一。
3. **大列表全量渲染**：LazySection/显示更多仅公共库屏接入；我的曲库 2000 首仍是全量 map。修法：同款「首屏50+显示更多」推广到 MyLibrary/CloudLibrary/歌单详情。
4. **黑胶转轴动效**：播放/暂停时盘体启停无缓动（isSpinning 硬切）。修法：Animated.timing 线性缓动+惯性感。
